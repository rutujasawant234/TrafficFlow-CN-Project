# TrafficFlow – Network Congestion Control Simulator

## Project Description
TrafficFlow is a Computer Networks mini project that visualizes network packet traffic and compares Leaky Bucket and Token Bucket algorithms for congestion control.

## Features
- Simulates network packet traffic.
- Compares Leaky Bucket and Token Bucket algorithms.
- Displays generated, transmitted, and dropped packets.
- Visualizes congestion control.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download the project files.
2. Open `index.html` in a web browser.
3. Click Start to run the simulation.
4. Compare the algorithms.
