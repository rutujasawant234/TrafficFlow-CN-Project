About TrafficFlow

TrafficFlow is a Network Congestion Control Simulator that demonstrates how Leaky Bucket and Token Bucket algorithms manage network packet traffic.

Project Objectives

  • Visualize packet transmission and packet loss.
  • Simulate network congestion using two algorithms.
  • Compare transmitted and dropped packets.
  • Understand how bucket capacity affects congestion.
